# HackTheBox Writeups

A running collection of writeups from HackTheBox machines I've completed — spanning
Windows, Linux, Active Directory, web application, and network exploitation challenges
across difficulty levels. Each writeup documents the full attack chain from initial
recon through to root/system, along with the reasoning behind each step.

> Writeups are only published once a machine is retired, per HTB's guidelines on
> sharing solutions for active machines.

## Machines

| Machine | OS | Difficulty | Focus Areas |
|---|---|---|---|
| [Support](machines/support/README.md) | Windows / AD | Easy | Anonymous SMB, .NET reverse engineering, LDAP credential exposure, BloodHound, RBCD, DCSync |
